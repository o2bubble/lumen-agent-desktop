# 文档元信息清理

AI 生成了 Word / Excel / PPT / PDF / 图片，文件里往往带着它不该带走的东西：

- **作者 / 最后一次保存者** —— 你的账户名
- **公司 / 管理者**
- **版本号 / 修订号** —— 内部迭代了多少轮
- **创建 / 修改 / 打印时间**
- **程序名称 / 总编辑时间**
- **缩略图** —— Word 存的是第一页渲染图，等于把正文带走了

平时这些藏在「文件 → 属性 → 详细信息」里，不点开看不见；可只要把文件发给外部，
对方右键就能读到。这个插件在每轮对话结束时自动清一遍，并**回读确认**真的没了。

## 覆盖范围

| 格式 | 处理方式 |
|---|---|
| `.docx` `.xlsx` `.pptx` | 改写 `docProps/core.xml` / `app.xml`，删除缩略图（连同指向它的关系） |
| `.pdf` | 清 Info 字典与 XMP。有 pymupdf 时用它；没有时用**原地等长覆写**（不改偏移，风险最低） |
| `.jpg` `.jpeg` | 删除 EXIF / XMP / IPTC / 注释段（字节级，不重新编码，画质无损） |
| `.png` | 删除 `eXIf` / `tEXt` / `iTXt` / `zTXt` / `tIME` 文本块 |

**不管** `.md` / `.txt` / 代码脚本 —— 那些本来就是纯文本，没有隐藏元信息。

## 怎么用

装好即生效，不用配置。默认**只处理本轮 AI 明确碰过的文件**，不会去动你其它的文档。

设置里可以改：

- **处理范围** —— 只处理碰过的 / 只处理新建的 / 工作区内本轮改动过的
- **抹除后写入的作者** —— 留空则彻底删掉；想统一署名就填一个
- **抹除后写入的公司** —— 同上
- **保留创建 / 修改时间** —— 归档类文档可能需要

## 它怎么保证真的清干净了

清理完会**重新打开文件逐项核对**：敏感字段必须已经不存在（或等于你配置的写入值）。
核对不过就拦住这次对话结束，让 AI 处理掉再收尾 —— 而不是默默放行。

PDF 遇到无法安全处理的结构（Info 字典被压进对象流、文档加密）会明确报出来，
让你知道「这个文件没清」，而不是假装成功。

## 「计算机」那一栏还会显示机器名 —— 这不是 bug

清理完之后你打开属性面板，会发现**「来源 → 计算机」仍然显示 `XXX (这台电脑)`**。
这是正常的，插件管不着也**不需要**管。

原因：这一栏不是文件里存的字段，而是 WPS / Windows 打开属性面板时**现场按当前这台电脑
算出来的**。证据：

- 在文件字节里搜不到这个机器名；
- 随便拿一个别人编译的二进制（比如 git 自带的 `bash.exe`），属性里照样显示你的机器名；
- 把文件改名、换目录，显示的永远是你自己这台电脑。

所以发给别人，对方看到的是**对方自己的机器名**，不会暴露你的。
哪天这一栏显示了**别人的**机器名，那才是真存在文件里的数据 —— 告诉我。

（图片 EXIF 里确实有 `HostComputer` 这种"拍摄/处理设备"标签，那个插件会删；
删完属性面板的「计算机」也还是显示本机名，同理。）

## 已知边界

- **WPS / Word 开着该文件时**写盘会失败，插件会报「文件可能被占用」。
- 清理的是**文件属性**，不包括正文里的水印、页眉、批注作者名。
- `.doc` / `.xls` / `.ppt`（97-2003 老格式）不支持。
- 图片只去元信息，不做像素级打码。
- 不处理 `docProps/custom.xml`（自定义属性）—— 极小众，本机实测 41 个 Office 文件零命中。

## 依赖

无。Office 与图片走 Python 标准库；PDF 在装了 `pymupdf` 时效果更彻底，没有也能处理常见文件。

## 卸载

钩子会随插件一起移除（宿主在下次插件重扫时对账），不需要手动改 `settings.json`。
