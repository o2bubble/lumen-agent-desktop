# Office 文档预览

在文件树里双击 Word 文档、Excel 表格或 PowerPoint 演示文稿，直接在编辑器里看。

## Word（`.docx`）

- **排版按原样还原** —— 段落、表格、图片、页眉页脚
- **缩放** —— 右上角 `+` / `−`，或点「适应」铺满宽度

## Excel（`.xlsx`）

- **还原 Excel 观感** —— Canvas 渲染，列标行列号、网格线、选中高亮
- **多工作表** —— 顶部标签切换
- **公式自动计算** —— 小计、合计等直接显示结果
- **合并单元格 + 样式** —— 底色、加粗、对齐、字体颜色、边框
- **条件格式** —— 色阶 / 数据条 / 图标集
- **冻结窗格** —— 表头固定不动
- **大表格流畅** —— Canvas 虚拟滚动（实测 6.7 万行）
- **Ctrl + 滚轮缩放**

## PowerPoint（`.pptx`）

- **幻灯片缩略图列表** —— 左侧点选快速跳转
- **主视图** —— 缩放（`+` / `−` / 适应窗口）
- **键盘导航** —— `←` `→` / `PgUp` `PgDn` / `Home` `End`
- **还原度高** —— 文本框、形状、表格、图片、组合都能正确渲染

## 通用

- **跟随主题** —— 深色/浅色自动切换外框
- **只读** —— 不会修改你的文件

## 支持范围

| 格式 | 支持 |
|---|---|
| `.docx` | ✅ |
| `.xlsx` | ✅ |
| `.pptx` | ✅ |
| `.doc` / `.xls` / `.ppt` | ❌ 旧版二进制格式，请另存为新格式 |

## 已知限制（PowerPoint）

- **图表（chart）不显示** —— 柱状图、饼图等会渲染成空白（图例还在）
- **动画 / 切换效果**不还原（静态预览本来也不需要）
- 极少数由程序（如 python-pptx）生成的形状组合可能漏渲染；
  用 PowerPoint 另存一次通常就好了

## 已知限制（Excel）

- **编辑功能不可用** —— 这是只读预览（编辑需要开 `editable`，本插件未启用）
- 图片/图表能显示，但**数据透视表**暂不渲染
- 超大文件（>10MB）解析需要几秒，期间会显示"正在解析…"

## 安全

插件只读取**当前工作区内**的文件，不会访问工作区之外的路径。
